## Game Data

The charm skill tables, slot tables, Melding Pot rules and quest reward tables in
[docs/talisman-data.js](docs/talisman-data.js) were read by the author from the game's own data and code
(dumped from a personally-owned copy). Only factual values are reproduced, in this project's own format; no
game files are redistributed.

The English skill names derive from the MHGU database (`mhgu.db`) bundled in
[JoeLago/MHGUDB-iOS](https://github.com/JoeLago/MHGUDB-iOS) (MIT-licensed), built on the community database
from [gatheringhallstudios/MHGenDatabase](https://github.com/gatheringhallstudios/MHGenDatabase), by way of the
sibling MHGU apps.
